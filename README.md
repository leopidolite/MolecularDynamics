# Molecular Dynamics for 2D Trimers

- Parallelized integrators for rigid 2D Lewis-Wahnstrom trimers in microcanonical, canonical, and isothermal-isobaric ensembles:
  - NVE via modified RATTLE [[doi:10.1016/0021-9991(83)90014-1](https://doi.org/10.1016/0021-9991(83)90014-1)]
  - Rigid-body NVT with Nosé-Hoover chain thermostat using Suzuki-Yoshida decomposition [[doi:10.1080/00268979600100761](https://doi.org/10.1080/00268979600100761)]
  - Rigid-body NPT via MTK equations and measure-preserving integrator, Yu et al. 2010 [[doi:10.1016/j.chemphys.2010.02.014](https://doi.org/10.1016/j.chemphys.2010.02.014)]
- Post-processing of trajectory files and analysis of structure and dynamics
- Scaled-particle theory (SPT) for analytical prediction of equations of state of hard-disk trimers

Running report on findings and theory: [**Updated July 2025**](https://drive.google.com/file/d/1Hn-c4JQkghMjLR84hISf_FqBBlLFT62q/view?usp=sharing)
